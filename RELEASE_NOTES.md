# LEM 1.0 RC2 — release notes

Data: 2026-09-13

## Zmiany względem materiału wejściowego

- ujednolicono nazwę jako Location Encoding Model;
- zdefiniowano dokładną postać kanoniczną i granicę równoważności;
- ujednolicono limit tekstu oraz dziedzinę `Level.value`;
- poprawiono i przeliczono przykłady TLV;
- przeklasyfikowano DNS-safe jako stratny alias prezentacyjny;
- dodano Related Work, porównanie zakresu i jawny wkład dokumentu;
- uruchomiono bibliografię BibTeX i usunięto ręcznie dublowany załącznik;
- dodano schematy JSON, YANG oraz wektory testowe;
- usunięto historyczne kopie rozdziałów `old-*` z pakietu wydawniczego.
- zastąpiono demonstracyjne URI `example.org` trwałą przestrzenią `https://w3id.org/lem/`;
- przyjęto organizacyjną własność infrastruktury projektu: repozytorium, konfigurację W3ID i wydania utrzymuje Politechnika Poznańska, Wydział Informatyki i Telekomunikacji, grupa badawcza pod kierunkiem Piotra Zwierzykowskiego, a nie konto prywatne.

## Potwierdzone decyzje właścicielskie

1. Autorstwo (potwierdzone 2026-09-13): jedynym autorem pozostaje mgr Piotr Augustyniak; prof. Piotr Zwierzykowski jest kierownikiem grupy badawczej, bez współautorstwa raportu.
2. Licencje (potwierdzone 2026-09-13): treść raportu, źródła LaTeX oraz autorskie tabele i diagramy są objęte CC BY 4.0; schematy JSON, moduł YANG, kod walidacyjny i wektory testowe są objęte Apache License 2.0. Logotypy PP, znaki towarowe, `ppfcmthesis.cls` i materiały osób trzecich są wyłączone.

3. Infrastruktura projektu (potwierdzone 2026-09-13): trwałą przestrzenią nazw jest `https://w3id.org/lem/`; właścicielem repozytorium, konfiguracji przekierowań i procesu wydawniczego jest **Politechnika Poznańska (Poznan University of Technology), Wydział Informatyki i Telekomunikacji (Faculty of Computing and Telecommunications), grupa badawcza pod kierunkiem Piotra Zwierzykowskiego**. Autorstwo Piotra Augustyniaka pozostaje bez zmian.

## Działanie administracyjne przed oznaczeniem FINAL

Należy utworzyć lub wskazać techniczny identyfikator organizacji GitHub dla wymienionej jednostki i grupy badawczej, umieścić w niej repozytorium LEM i zarejestrować przekierowania `w3id.org/lem`. Jest to wykonanie potwierdzonej decyzji, a nie otwarta decyzja o modelu własności.
